# V14 绵柔时长与任意配色

本轮完成可调的扩散、停留、淡出，以及从键盘工具栏进入的原生光效设置页。仍为待确认的 V14，不触发发布。

## 行为

- 默认波纹：点亮 100ms、扩散 1400ms、停留 350ms、淡出 900ms，总计 2750ms；键面保持及退场单独计时。
- 扩散可选 100–4000ms，波纹停留 0–2000ms，淡出 100–5000ms；设置控制实际波纹生命周期，远端光不再使用固定的 1000ms 截止时间。
- 随机多彩、任意 RGB 单色、自选 1–8 色搭配。每次按键选出的颜色同时用于键面、弹字和流光。
- HSV 与 HEX 原生编辑器；保存后偏好变化通知会重建键盘。原配色和旧设置可读取，初次打开不会改写时长。
- 快速输入优先保留当前键附近的新光；候选栏弱柔光独立限制叠加，已减弱的局部光和远端光都不会在停打后重新变亮。

## 预览来源

动图与视频由生产 Android 视图和真实触摸分发生成的 PNG 序列直接编码，没有重新绘制键盘或修改亮度、颜色。

- `v14-soft-continuous`：真实 TextKeyboard、CandidateUi、RippleBarView、PopupEntryUi。150ms 一键，按住 50ms，末次按键之后保留整个波纹生命周期及回黑时间。
- `v14-soft-single-press`：隔离单次 G 按键，50ms 松手；此场景不挂载弹字和候选栏。
- 默认预览明确使用 Random/Cyberpunk，固定随机种子 1401；关闭闲置呼吸，以免把呼吸光误认作按键尾光。
- 原始 600px、20fps 帧直接编码；GIF 缩为 480px，MP4 保留原尺寸。它们是 Robolectric NATIVE 渲染预览，非手机录屏。
- 候选文字回放自真实配套 Rime 的候选验证记录；这个 UI 测试不直接运行手机 ARM 引擎。
- 设置页与颜色编辑器使用生产原生控件绘制；动画设置图展示真实滚动位置的控件。

## 验证结果

本地全量 104 项、17 个测试类全部通过，零失败、错误和跳过。保留原有暗底与可见性门槛：原四条键缝平均亮度 69.10（限制 75），候选栏清空白带至少 15% 的彩色区域连续可见 8 帧（要求 6 帧），候选栏平均亮度峰值 34.04（限制 45）。输入期键外彩光峰值面积 18,382 像素，65 个输入帧保持可见。具体数据在 `test-summary.json` 和原始 `visibility.csv`。

GIF 134/65 帧、每帧 50ms；MP4 6.70/3.25 秒，600×420 / 600×360，逐帧计数和完整解码通过。设置页截图实际查看通过；时长页以真实 ScrollView 的滚动位置绘制原生子控件，绕过 Robolectric 的旧 ScrollView 显示缓存，保留真实位置与滑杆像素验证。
