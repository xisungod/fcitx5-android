# 连续输入与跟手预览

生产光效缩短默认点亮等待为 40ms，扩散的前后两段以非零速度衔接，新旧光的优先级与亮度预算平顺交接。波纹仍分别保存各次按键的寿命；保留固定键帽轮廓、固定弹字尺寸、连续字色和用户设置的停留/淡出时长。

旧底场叠加上限收至 0.30，新底场保留 1.50，候选桥保留 0.40；当前键面和弹字颜色没有调低。预算过渡采用平滑限幅，旧光被压低后不重新变亮。连续输入的原黑底门槛保持不变，新增两键合计上限断言收紧为 1.80，同时保留旧光可见性与交接速度检查。

光效设置新增点亮等待滑块（30–300ms）。默认一次波纹是 40ms 点亮、1400ms 扩散、350ms 停留、900ms 淡出，共 2690ms；已保存的点亮时间继续使用原值，页面总时长与说明随滑块保存更新。

## 预览

- `v14-continuous-typing-60fps.mp4`：七次不等间隔连续输入，真实 DOWN 在 0、105、230、320、440、545、650ms，UP 均在 50ms 后。
- `v14-continuous-single-60fps.mp4`：单键 F，数字行开启。
- `v14-continuous-number-off-60fps.mp4`：同一单键，数字行关闭。
- 对应 `*-30fps.gif`：从原始 60fps 帧每隔一帧抽样的备用动图。GIF 的百分之一秒时间精度无法完整表达均匀 60fps，应优先看 MP4。

所有帧都来自 Android 生产视图的 Robolectric NATIVE 实际绘制，时间戳是 `floor(frame*1000/60)`；没有插帧，没有事后平滑或改亮度。预览是代码绘制，非手机录屏。候选词使用仓库真实 Rime 候选记录夹具，没有在这里运行手机 ARM 引擎。

每条序列记录实际键帽/主字坐标及绘制基线、字色和可读性、键外流场的逐帧变化，并保留完整退场和黑色停留。原 20/30fps 序列和亮度、可读性、候选栏门槛继续验证。真机帧耗时和触控延迟尚未测量，不能用这些离线帧宣称手机一定不掉帧。

扩散结束后按设置保持形状 350ms，再淡出；这段停留会有相同帧。快速输入和 200ms 的局部连接段保持连续推进，停打后的新旧光逐渐收暗。三个序列的最后键盘画面都与各自静止基线逐像素相同。
