# V09 按键动画、滑动选键与独立数字行

构建提交：`8c9baa554a144da88a8cd89733ec1a1b18b6543c`
构建记录：https://github.com/xisungod/fcitx5-android/actions/runs/37166511898

## 本次改动

- 键面颜色改在深灰键帽背景之后、字符之前绘制，不再被半透明键帽压暗；硬件缓存的各键面随动画一起刷新。
- 外围光晕随着扩散降低亮度，减轻连续输入时整片彩色背景的积累，让每个键的停留、收缩过程更清楚。
- 字符预览的背景只包围上方字符，下半部透明，避免按住时用黑色长条遮住当前键帽。

- 键面默认保持颜色 260 ms，随后用 480 ms 从圆角色块收缩到小圆点，在收缩后半段淡出；停留与收缩淡出时间分别可设置。
- 外围波纹半径在已有大小设置基础上缩小 15%，键面停留/收缩时间不变。
- 外围同色光晕延后 100 ms 启动，默认 900 ms 平滑扩散、450 ms 消退。扩散曲线放慢开始阶段，继续覆盖候选栏。功能键保持柔和圆形反馈。
- 增加 4 dp 内抬手漂移容差；系统合并最后一次 MOVE 时仍根据 UP 确认最终字母，远离键盘和落在功能键上仍取消。抬手重选键后再次释放呼吸光状态，避免一直误判按住。
- 字母与数字间拖动更新当前键的颜色和字符预览；只在松手时输入最终选中的键。保留长按字符菜单选择；空格光标和退格手势保持原用途。每根手指单独跟踪，取消触摸不输入字符。
- 竖屏默认显示独立的 1–0 数字行，移除 QWERTY 字母上的数字角标；默认键盘高度从 26% 调为 32%，保持每排的可触摸高度。
- 修复数字行导致字母大小写更新提前退出的问题；英文显示小写与“英”，Shift 仍正常。
- 符号按钮直接显示常用符号：首页第一排为中文标点，不再重复普通数字。重新打开回到常用分类，更多符号仍可滑动或切换分类；123 继续打开数字键盘。
