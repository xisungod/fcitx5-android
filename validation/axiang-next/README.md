# 阿翔输入法键盘控制改进验证

本轮开发包为 `1.1-dev`，包名 `org.fcitx.fcitx5.android.axiang.dev.controls`，arm64。未发布新正式版。

- `test-summary.json` 与 `test-results/`：37 类、226 项检查全部通过，失败、错误、跳过为 0；`test-build-log.txt` 是成功构建与完整测试的日志。
- `patch-check.json`：累计补丁对固定上游基线干净应用，218 个变更路径与已提交源码逐字节一致。
- `verification-result.json`、`bundled-rime-check.log`：最终主 APK 签名、名称/版本/架构、离线权限、Rime 原生引擎/注册、145 个资产描述符文件及摘要、完整词库/预编译数据、OpenCC 和许可来源全部通过。
- `keyboard-controls/`、`icon-checks/`、`ripple-shape-checks/`：实际 Android View/Drawable 的 Robolectric Native 渲染；已经人工查看高度编辑、键盘内设置、色卡、形状选择、收起图案、应用图标与两类光场。
- `typing/`：连续真实触摸回放的光场测量，保留候选栏微弱联动、亮度上限、暗键面和停打退光的原验证阈值。

新增检查覆盖：高度预览/保存/取消/横竖屏隔离/多指/无障碍；设置草稿及真实工具栏进入/返回/完成；空格四向；回车短按/长按/双指不误发送；按键位置与速度连续、短按及时退回；配色、默认柔雾与流体连续形变；新图标兼容；Rime 初始配置与保留自定义配置；无联网/录音/系统识别声明及关闭备份。

这里的图像和测试不等同于手机实测，不证明特定机型的 FPS、触摸延迟或主观手感。预编译 Rime 数据来自固定来源，其来源和文件摘要随 APK 验证；主机候选验证见既有词库记录与 CI 预编译步骤。

测试 APK 与公开 1.0 的签名不同，因此使用独立包名并存，不可作为覆盖升级包。正式发布仍需确定可持续保管的签名方案。第三方 darts-clone 许可原文保留了上游两处行末空格；应用源码的空白检查通过。
