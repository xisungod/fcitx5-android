# touch.10 修复复核

本轮基于 `claude/voice-accuracy-motion` 的 `a5371f0141056240198f5909f1b34ae02efd4010`。

## SAM 光效

原实现将一整片椭圆光场统一变暗，并让每次按键的边缘和尾段自动偏向蓝紫色；连按容易混成大面积近似颜色。现在按各位置的到达时间分别衰退，保留有厚度的连续尾光，使源头先暗、外围后退。每次按键保持自己的颜色，不同来源仅在相交处混合。

传播尺度使用实际触摸格的短边，不再假设固定十列。默认传播范围受面板尺寸约束，羽化范围随键距变化。未按键的黑色遮罩加深；按下键面的颜色和回弹仍独立运行。没有重写按键弹簧，也没有让新一次按键或松手重启旧波。

参考仍为 [原视频观察记录](../sam-wave-touch-fix/video-reference.md) 中两段 SHA-256 已核对的录像。本轮重看了第一段 10.403–11.397 秒和第二段 7.733–8.533 秒。视频支持中心与外围衰退的先后关系，不能用于测量精确触摸时刻、弹簧参数或绝对亮度。本轮的范围、黑度及 400ms 扩散 / 40ms 局部保持 / 900ms 衰退均是设计选择，不声称是三星内部参数。

## 触摸布局回归

touch.9 默认开启扩大触摸区域后，`KeyView.onLayout` 中调用 `setLayoutParams` 又请求了一轮布局。现在在当次布局中更新边距并按当前尺寸测量可见键面，避免多余遍历，同时保留扩大的命中区域。

测试同时修正了可见键面与触摸格的混用：像素和颜色应采样实际 appearance 范围，而不是新增的透明命中区域。SoftMist 的实色填充断言明确选择 SoftMist；SAM 由独立的原生绘制测试覆盖。没有关闭扩大命中区域或放宽原断言来规避失败。测试宿主中窗口尺寸变化会放大布局问题，不能把其越界和光标位移幅度直接当成真机表现。

## 学习与离线听写

- 学习开关的两种切换都会撤销排队任务，普通提交在实际入库前再次检查授权。未改为保存原始输入文本。
- 普通未编辑上屏仅计 1/8 权重；明确纠错、校准保留完整权重。8 次明确证据或 64 次普通证据才达到同等起效门槛。旧版数值统计兼容迁移，无法追溯其证据来源；1/8 是保守防误学策略，不是经过真机优化的常数。
- 模型加载有 20 秒期限，取消不再等待 native 构造；迟到结果由加载任务负责清理。单一加载槽避免不断重试产生并行 native 分配。
- 停止期间仍受加载期限约束；切换编辑器和取消使迟到文字失效。已经进入 JNI 的 decode/finish 无法安全强制终止。
- 模型的两分钟空闲缓存改用一个可取消任务，低内存时异步回收。停止听写后不继续录音、推理。
- 静默计时参考声音能量活动和状态，不再只看文字是否变化；冷加载使用单独期限。能量门限并非语义 VAD，环境噪声仍可能延长会话。

## 可复核产物

GitHub Actions 的 checks artifact 现在包含 `app/build/outputs/effect-checks/`：

- `sam-propagation/`：传播、局部衰退、单波颜色、双来源与键距 PNG/CSV。
- `dev8-sam/`：生产键盘单按、连续输入帧及运动数据，目录名沿用既有测试。
- `probe/`：默认设置的单按、连续输入、长按后松开 contact sheet。

使用生产绘制路径和 Robolectric native graphics；这些产物不能代替手机上的帧耗时、触摸延迟和听写耗电测试。APK 使用 CI 校验过的既有 351 个 assets 与 29 个 ARM64 native libraries，本轮不更换词库、模型或原生引擎。
