# V14 正确三星参考与数字行开关

本轮以用户更正上传的 11.1 秒三星键盘视频为参考；误传的 SVID 不作为本轮动画依据。用户录像与其抽帧不上传到仓库。

## 参考中实际可见的表现

按下的键帽整颗变亮；紫、蓝、青、绿底场沿键隙铺开并覆盖，未按键帽保持深色，形成键帽浮在光面上的层次。没有清晰空心圆环，也不只是一个不断变大的模糊光点。

6.733 秒手指附近出现紫光，6.933 秒开始铺向邻区，7.067 秒连成大片。最后一组连击在约 7.667 秒停止后，7.933 秒底光仍明显，8.0–8.333 秒渐退，8.533 秒基本回黑。此段只能说明连击尾光约 0.8–1 秒，不能据手指遮挡的拍摄视频推算单键精确寿命。

参考弹字为黑底白字，光也未明显越过键盘上缘。本版继续满足用户先前明确要求：本次键面、弹字与流光共享按键颜色，远端弱光可延伸候选栏。

## 数字行

工具栏调色盘进入的设置页增加“显示顶部数字行”，主题设置也保留同一开关。它绑定现有竖屏主题偏好；关闭时真实布局从五行变四行，字母键与触区一起增高，保留 `123` 九宫格入口。主题偏好也同步到设备加密存储。

## 本轮修改

正常键帽及空格使用深炭灰且提高遮光程度，压下未按键帽的透色。底场从中心强、外围弱的 Gaussian 雾状遮罩改为近乎平坦的实心光面，保留圆角与柔和前沿，降低形状噪点与球状末态。局部扩散参数从 0.76 收为 0.68，局部 alpha 增加 20%；远端候选桥、叠加预算和配置时长保持原值。

自选颜色的弹字改为比较现有深字和白字在实际背景上的对比，选择更清楚的一种；原色、字号和动画时长不变，中灰色真实弹字也通过验证。

## 预览来源

预览由生产 TextKeyboard、PopupEntryUi 等 Android 视图接受真实触摸后，以 Robolectric NATIVE 绘制的原始 PNG 编码；不是手机录屏。数字行开/关使用固定青色及同尺寸键盘便于比较，默认配色仍为随机多彩。

短连击预览使用随机多彩，展示输入期间的色场覆盖，以及末次按键后完整尾光与回黑。帧的原始颜色和亮度不做后期修改；GIF 缩为 480px，MP4 保留原尺寸。编码脚本与实际测试记录同目录保存。

设置页截图演示自选配色；主程序和短连击预览的默认配色仍为 Random/Cyberpunk。闲置呼吸在动作预览中关闭，便于区分按键尾光；功能本身保留。

## 验证结果

最终本地全量 110 项、17 类全部通过，零失败、错误或跳过。保留原四条暗缝亮度上限 75，实测 74.1132；主键缝平均亮度峰值 59.47（上限 70），候选栏平均峰值 33.21（上限 45）。候选栏至少 15% 空白带有色光连续可见 7 帧，超过原 6 帧要求。仍验证停打不突然重新洗亮，以及完整尾段后回黑。

与本轮较宽的光面相比，同种子、同帧窗口的全帧平均亮度仅增加约 0.27%–0.51%；单 F 的外部高亮面积缩小，局部光面更集中。指标用于比较本版实现，不能据拍摄视频推断三星的绝对屏幕亮度。

数字行开/关各 65 帧，20fps、3.25 秒；短连击 85 帧，20fps、4.25 秒，包含末次按键后完整生命周期与 550ms 回黑。GIF 帧数、时长、MP4 帧数及完整解码均通过。原始 XML 在 `test-results/`，统计与前后比较见 `test-summary.json`，编码校验见 `media-check.json`。
