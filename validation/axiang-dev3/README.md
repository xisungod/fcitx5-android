# 阿翔输入法 1.1-dev.3 验证记录

源码提交：`26b74ed1ed846ad25a9916507de0556459e0de30`。

本次根据真机反馈修复流体键面上暗下亮的问题，并延长柔雾的可见动作与尾光：

- 整块键面使用完整彩色，流体仅在顶缘保留细小同色亮光；内区与柔雾同时间逐像素一致，上下半面颜色接近，字符位于光效之上。
- 首帧浮起由 35% 提高至 45%，松手回落约 0.8–0.9 秒；输入提交和按下反馈不等待动画，短触及连续重按保留位置和速度衔接。
- 柔雾采用二次亮度衰减，默认消退时间由 520ms 改为 900ms，默认波纹完整时长 1380ms；保存过的 520ms 和其他自定义时长保持不变。流体的衰减曲线、两种模式的亮度上限和空间范围保持原约束。
- 原生像素测试覆盖整面颜色、保存 520ms 与新默认 900ms 的可见尾光和准确终点；实际键盘对照录制至 1800ms。现有短触、连续输入、隐藏停帧、文字可读性及完整尾光检查保留。
