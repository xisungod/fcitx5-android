# V14 发布核验

用户已明确要求“先发布”。发布目标为已核实的 `xisungod/fcitx5-android` 仓库、`improve/keyscafe-black-v14` 分支和 `xuancai-black-v14` Release。

键盘 UI 与通过本地 120 项检查的源码相同。发布前修正了主程序 Gradle 中硬编码的包名后缀，使其继承与 Rime 相同的包名配置。独立和固定两种包名模式均通过实际合并清单核验；固定签名凭据没有在本地读取或使用。

APK 校验保留完整词库与预编译数据的哈希核验，新增对实际二进制清单的宿主一致性、版本 802 和 arm64 检查；任一不匹配会阻止发布。解析器的 14 个正常/错误案例使用 aapt 生成的合成 APK，不当作最终产物验证。发布 CI 会再次运行完整界面测试、实际 Rime 候选与最终 APK 核验。

`patch-check.json` 记录完整补丁的干净应用与 103 文件逐字节一致性；`manifest-check.json` 与两组实际 XML 记录独立/固定包名核验。后续发布状态与实际产物核验单独记录，历史预览资料保持原样。
