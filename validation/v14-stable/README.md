# 按键视觉稳定性预览

这组预览由生产 `TextKeyboard`、`PopupEntryUi` 和候选栏视图经 Robolectric NATIVE 绘制生成。单键轻点 50ms；连续输入 `liangge` 每 150ms 一个键。每秒 30 帧均是实际时间戳的原生绘制，没有补帧；GIF 使用其格式要求的百分之一秒时间精度，MP4 保留 30fps。不是手机录屏。

本轮调整：弹字只淡入淡出、固定尺寸；键帽使用固定细内轮廓；周围光场更平缓地起步；字色连续过渡，固定 0.8dp 描边避免灰色字形消失。已有流光、任意配色和时长、数字行开关保留。

## 查看

- `v14-stable-typing.gif` / `.mp4`：七键连续输入，完整退场到黑色。
- `v14-stable-single.gif` / `.mp4`：单键 F 轻点，顶部数字行开启。
- `v14-stable-number-off.gif` / `.mp4`：同一轻点，数字行关闭。
- 各序列的 `ink.csv`、`geometry.csv`、`visibility.csv` 与 `preview.txt`：实际字色、字形与键帽坐标、底场亮度、时间参数及来源。
- `media-check.json`：编码帧数、时长与完整解码结果。
- `test-summary.json` / `test-results/`：最终统一验证记录。
- `patch-check.json`：干净源码基线应用完整补丁后与已测源文件的逐字节核验。

连续输入的候选词来自仓库真实 Rime 候选记录夹具，用于候选栏界面绘制和输入事件验证；没有在这里执行手机 ARM Rime 引擎。这组预览可检查动画和布局，真机触感仍待安装验证。

旧的 20fps 序列与门槛保留，新预览额外逐帧验证固定坐标、基线和绘制尺寸、弹字 scale=1、实际字形与背景对比，以及完整黑色停留。代码和预览仅保存在本地，此轮没有尝试推送、触发 CI 或发布。

最终完整验证为 18 类、115 项全部通过，零失败、错误或跳过。数字行开/关各 97 帧、连续输入 127 帧，实际坐标与绘制基线没有变化；单键退色时相邻字色通道最大步长 26，主字的实际可读面积全程满足原生对比门槛。三个序列最后的键盘像素均与其静止基线一致，候选栏也完全回黑。
