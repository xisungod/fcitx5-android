# V14 流光修正版

本轮修复首轮 V14 预览中「键面明显变色，但外扩流光不明显」的问题。

## 修改

- 原先新光和旧光共用一个过低的亮度上限，连打时新光也被压暗。现按年龄平滑分配叠加额度，近期光保持可见。
- 已经减弱的光保留其衰减系数，不会因为其他光消失而重新变亮。
- 扩散早段更快起步，保持用户设置的总时长。羽化遮罩增强不规则亮肩、内部轻微形变，并保持实心中心。
- 主云局部范围缩为原来的 76%；较旧的主云单独减弱，候选栏远端柔光单独退场，避免整片背景持续明亮。
- 键面与弹字共用本次按键颜色。修正旧键面延迟过期时误删新颜色的时序问题。
- 数字九宫格、分类符号页、空格图标、Rime 词库和输入功能保持原 V14 实现。

## 预览来源

GIF 和 MP4 由生产 Android 视图及触摸路径绘制的 PNG 序列直接编码；没有增加亮度、重绘键盘或人为修改光效。它们是 Robolectric NATIVE 渲染，非手机录屏。

- `v14-flow-single-press`：按下 G，50ms 松手，查看键面退场及键外扩散；此隔离场景不挂载弹字和候选栏。
- `v14-flow-continuous`：真实 TextKeyboard / CandidateUi / RippleBarView / PopupEntryUi，每 150ms 一键、按住 50ms。候选数据回放自配套真实 Rime 验证记录。
- 固定此测试的随机种子 1401 使审核可重现；APK 每次按键仍随机选择霓虹色。
- 600px 原始帧以 20fps 编码，GIF 缩至 480px。详细坐标、面积和亮度时间序列见 `preview-source.txt`、`visibility.csv`。

目前呈现为不规则柔雾流光，不能将此预览当作与三星闭源效果完全一致的证明。仍等待视觉确认，本轮没有发布安装包。

## 本地验证

85 项测试、15 个类全部通过，零失败、错误或跳过。原有四条键缝扫描的 `<75` 约束保持，实测 72.20；新测试排除键面、弹字和静态光晕后，连续输入外扩彩光峰值面积 18,838 像素，65 个输入帧全部保持可见。候选栏有色区域连续可见 10 帧，停止输入后没有旧光回亮。
