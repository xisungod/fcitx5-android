# AXiang 1.2-touch.7.1

此补丁修复 touch.7 在连续输入、候选项复用时，候选汉字意外变小的问题。

候选渲染组件使用自己的测量和排版逻辑，但此前没有在文本更新时明确请求重新测量。短词变成长词后，横向候选列表可能仍使用短词的旧宽度，导致整段文字被压缩；新建的候选项则保持正常大小。

修复在候选文本更新时清除旧排版并请求重新测量、重绘。正文继续使用 24sp，拼音注释使用正文的 0.625 倍，纠错星号使用正文的 0.55 倍并略微上移。候选项保留原有点击区域和展开列表的布局行为。

验证包括真实 RecyclerView 中从短词增长到 `hhh` 五个三字候选的视图复用，以及退格、清空、注释样式变化后的绘制。验证比较实际渲染像素，避免只检查字号属性而漏掉画布缩放。

补丁沿用 touch.7 的包名和持久测试签名，可直接覆盖安装。输入处理、Rime、词库、触点纠错及个人校准逻辑沿用 touch.7；发行校验材料分别说明本次 UI 回归结果与原生库继承证据，不将上一版测试冒充为本次重新执行的结果。
