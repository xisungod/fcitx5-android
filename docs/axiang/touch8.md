# AXiang 1.2-touch.8：离线下一词联想

本测试版在 touch.7.1 的基础上增加下一词联想，继续使用同一个测试应用包和签名，可直接覆盖安装。候选正文保持正常字号；星号与拼音提示仍采用较小字号。

## 怎么使用

1. 在普通中文输入框中输入并上屏，例如“谢谢”。
2. 停止输入时，候选栏提供“你、你们、大家”等下一词建议。具体排序取决于内置词模型，并不保证符合每句话的本意。
3. 点选一个联想词即可上屏，随后继续联想。直接打字会立即收起联想，进入原来的拼音输入。
4. 空格和回车保留原来的输入、换行操作，不能选中联想词。

“设置 → 输入与纠错 → 联想输入 → 上屏后联想下一词”默认开启，用户可以随时关闭。密码、应用标记的敏感或禁止学习输入框，以及邮箱、网址和数字输入框不运行联想。英文模式不显示联想。

## 技术与数据

联想使用安装包原有的 libime 主语言模型和 `.predict` 索引，不添加神经模型或新的词库，也不修改 Rime。新增的原生桥接库仅用于只读查询。预测在独立后台线程执行；过期查询结果、切换输入框前的结果和已失效的候选点击会被丢弃。单次查询超时不会停用后续查询。

本版不做个人化学习，不保存日常输入记录，也不读取输入框的周边文本。只在当前输入框的内存中保留最多 64 个汉字的近期成功上屏上下文；移动光标、删除、切换模式、隐藏键盘或更换输入框会清除上下文。句末标点及非中文内容也会断开上下文。

## 怎么验证

- 输入“谢谢”并上屏，检查联想是否出现；点选“你”后应仅输入一次，并继续提供下一词。
- 联想出现时直接输入拼音，检查旧联想立即消失；空格、回车不能误选联想。
- 输入框切换、敏感框和英文模式不应带入旧联想。
- 原有拼音纠错、候选字号、明确滑动选键和双指输入继续走原来的处理路径。

打字测试报告新增联想实际显示数、成功采用数、采用率、目标对齐覆盖率、估算省下的拼音字母数，以及上屏成功至实际绘制的延迟。只有已知目标和明确拼音映射可靠对齐时才估算省键；目标已完成、缺少映射或编辑过上下文时显示不可评，不把缺证据当成零误差。联想输入不作为手打拼音或触点学习的真值。

冷启动与已初始化查询的耗时分开报告，查询不可用、失败和超时会标明。后台查询的耗时不等于屏幕显示延迟。

## 验证范围

构建流程执行整个应用的 JVM/Robolectric 回归，并重新编译、验证本版联想桥接。原生检查使用真实 Android ARM64 库、安装包原有模型和 bionic 运行时；其中 JNI 测试使用模拟接口，不等于手机上的 ART 安装运行测试。原有 Rime 和所有模型资产保持字节一致，其既有验证明确继承。

真实手机的准确率、采用率、耗电和显示延迟仍需要使用本版测试报告验证；本版不承诺上屏后 10 毫秒内显示。
