# AXiang 诊断测试：你需要做什么

这个包叫“AXiang 诊断”，版本 1.2-diagnostic.1，与原 AXiang 并存。请保留原应用；测试时在系统输入法选择器中切换到 AXiang 诊断。新包的词库和设置独立，使用与你平时相同的键盘布局、尺寸即可。两种对照模式始终用这同一个测试包。

本次测量按键误触原因，暂不改变按键顺序和拼音解码。边界改判默认开，日志默认关；没有加入神经纠错或重排模型。

## 先做一对简单测试

1. 安装 APK，按应用引导启用并切换到“AXiang 诊断”，选择中文全拼。若键盘尺寸不同，先调整到你平常使用的尺寸。
2. 打开“更多设置 → 输入与候选 → 输入诊断 · 对照实验”。开启“记录本机输入诊断”，清空旧诊断，保持“自动边界改判”为开。
3. 在备忘录的普通文本框里，按自然速度输入“你好啊”（nihaoa）。先不要点汉字候选，保留实际拼音；如果敲错，先保留这次原输入，避免用事后修正覆盖原结果。
4. 切换“自动边界改判”为关，清空输入框，按同样速度再打一遍 nihaoa。不要修改键盘尺寸或其它设置。
5. 回到诊断设置，点击“预览并导出诊断”，保存为 01-你好啊-先开后关.jsonl。将这个文件发给我，并说明“这一对目标都是 nihaoa”。截图可辅助查看，但不能替代日志。导出后清空本机诊断，再开始下一句。

如果状态仍是 0 条记录，先确认当前用的是 AXiang 诊断，日志已开启，测试框为普通文本框。

不必运行脚本或自己标注每个触点。你确认每段原本想输入什么，我负责核对范围、标注和回放分析。先把第一对发来即可检查采集是否完整，然后再完成下面固定流程。
