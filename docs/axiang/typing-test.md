# AXiang 1.2-touch.3 打字测试

这一版在 touch.2 的双指顺序和触点候选实验上增加“打字测试”。键盘判断、纠错阈值、词库、原生查询线程和个人化默认设置延续 touch.2。本次主要让同一套固定题目产生可比较的手机测量结果，尚不证明准确率或手感已经提升。

## 安装后怎么用

本包版本为 `1.2-touch.3`，版本号为 `3`。应用和输入法名称保持“AXiang 触点测试2”；包名、持久测试签名与 touch.2 相同，可覆盖升级已安装的 touch.2，保留它的设置与词库。原 AXiang、touch.1 和诊断包仍是独立应用。升级身份以实际 APK 签名和包名核验为准。

在 AXiang 设置首页打开“打字测试”，先选 **5 句快速测试**，几分钟内即可完成；需要更完整的样本再选 **20 句完整测试**。选中 AXiang 输入法，选择中文全拼，按页面给出的拼音顺序输入整句，再选择候选上屏。拼音提示默认显示，熟悉后可收起。题目不用输入声调或标点；“绿色的旅行”中 `v` 表示 `ü`。

按照平时速度和握持方式打，出现错误可自然退格或选择候选。不要为了测分故意按准、故意输错。文字上屏后点“完成这句”，确认结果后点“下一句”；最后点“查看结果”。即使最终文字不对也可以完成该题，报告会照实统计。完成后页面显示报告，可导出 JSON，也可清除本机报告。导出后可以把文件发回来分析，不需要另开诊断日志。测试中旋转屏幕或重建页面时，已完成题目保留，未完成题目重新开始并记录丢弃次数，避免把两种布局的数据混在同一次输入中。

## 报告测的是什么

- **原拼音编辑率、相邻键替换率**：比较已完整采集、符合题目全拼约定的首次拼音与目标串；相邻键替换另行统计。原拼音编辑距离仍可计算时，错误较多也照实计数；超过相邻键对齐预算、有多种同样合理对齐的记录，不猜测是哪一个邻键错了。提前退格冻结的前缀和不完整记录不猜测尚未输入的后半句。
- **第一、前三候选命中率**：首次按约定输入到整句长度时，冻结与那一代原拼音一致的候选快照，在退格或选词前保留它。目标汉字在第一位或前三位才算命中；后续选对或退格重打不会把早先未命中改成命中。这里统计原 Rime 候选列表，不把旁边独立的 `*` 建议算进前三位；完成率与退格负担可以反映它的使用效果，当前报告没有单独的 `*` 命中指标。
- **退格率**：退格次数除以实际字母按键数，报告保留分子和分母。它反映这组题目的修改负担，不能独自证明是哪种机制导致了错误。
- **按键处理时间**：记录手机上的 `enqueue_to_key_action_completion_ns`，即字母动作入队至处理回调完成的时间，包含队列等待和该动作处理；测试中的前一次测量任务也可能影响等待。汇总实际单键样本的 p50、p95 和最大值，不平均各题的 p95。它不包含最终屏幕绘制、触摸至光效出现或触摸至上屏的完整延迟，也不是孤立测出的纠错算法新增开销，不能直接当作“体感延迟”。

首选与相邻键指标只对可评分样本计算，并显示分母和未评分原因。简拼、混合输入、分段选词、外部输入、提前删字或记录缺失可能使部分指标无分数；**未评分不当成零错误，也不当成成功**。报告同时记录实际完成题数，便于判断覆盖是否足够。短测试里每题的候选命中只贡献一个样本，偶然差异很大，不能据此宣称误纠率已经低于千分之一。

## 比较版本与开关

日常使用的“双指快打顺序（实验）”“触点候选纠错（实验）”默认开启，既有安装中自己修改过的开关会保留。测试不需要先启用诊断或习惯学习。带 `*` 的补充候选仍需明确点选，原始拼音和原候选保留。

做对照时保持布局、键盘大小、方向、握持方式和速度相近，每轮使用同一组题目，一次只改一个开关；交替两种模式的测试先后，再比较可评分样本、退格率、候选命中和处理时间。报告提供测量依据，并不自动宣布发布门槛通过。单个“经常会”例子只用作回归，不能代表日常准确率。

## 数据与学习边界

测试只在应用内的专用测试输入框采集当前题目。离开测试、切换编辑框或结束测试后停止；普通聊天、密码框和其它应用不纳入题目记录。独立诊断日志仍默认关闭，不随测试打开。

报告保存在本机应用私有、不参与系统备份的目录，最多保留最近三份，每份不超过 512 KiB。导出是主动的系统文件保存操作；导出的文件由用户自行管理，清除本机报告不会删除已经导出的副本。报告含固定题目、测得的拼音、触点证据、选词快照、处理时间和未评分原因，分享前可自行查看。

已成功完成题目、符合全拼约定且触点与拼音能可靠对齐的片段可形成**待核对的校准样本**。知道目标句子并不代表每一下触摸都能自动确定原意；漏按、多按、多解对齐和不完整输入受到排除。当前版本不会把这些样本自动写入落点模型，不自动开启按键习惯学习，也不从猜测、普通选词或删字重打训练个人化。

## 下一阶段

个人化落点模型、高把握自动改拼音、增加漏字/多字/交换搜索、多个备选、独立 Rime 查询线程、上下文候选重排和神经网络都没有在这一版新增。特别是备选只读查询仍使用 touch.2 的输入线程；本次报告中的处理时间可以帮助发现队列等待，但还不是“独立线程已完成”的证明。

以多轮真实手机测试的准确率、可评分覆盖、误纠、处理时间和手感为依据，再单独推进下一项。已有只读探测对象不能直接跨线程使用；独立线程方案还需核实 Rime 生命周期、词库访问和线程隔离。

## 构建核验

交付脚本 `scripts/prepare-axiang-typing-test-delivery.py` 固定复用公开 touch.2 APK 的完整 **350 个资源文件和 28 个 ARM64 原生库**，要求全部逐字节一致，没有新增或修改词库、拼音概率表、语法模型、神经模型或原生库。

脚本检查实际 APK 包名、版本、签名和 16 KiB 对齐，读取 DEX 中的 `BuildConfig.BUILD_GIT_HASH` 并与干净冻结的源码提交比对；汇总全部实际 JUnit XML 并打包报告。源码补丁只含公开 Kotlin、XML、Python 和说明文档，不含测试输入报告、原始诊断日志、编译产物或签名密钥。发布文件以 `build-verification.json`、`unit-test-summary.json`、`source-snapshot.json` 和 `SHA256SUMS.txt` 的实际结果为准；本地测试通过不等于手机准确率或延迟目标已通过。
